# RPA Backlog Demo

Vercel/Next.js ile hazırlanmış, verileri tarayıcı LocalStorage'ında tutan demo RPA backlog uygulaması.

## Çalıştırma
```bash
npm install
npm run dev
```

## Vercel
Projeyi GitHub'a yükleyip Vercel'de **New Project > Import Git Repository** ile bağlayın. Build ayarları Next.js için otomatik algılanır.

Bu sürümde backend/veritabanı yoktur. Her tarayıcı kendi verisini tutar.
